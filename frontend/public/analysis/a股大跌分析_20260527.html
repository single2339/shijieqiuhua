三、五层原因拆解

第一层：直接导火索 — DeepSeek "价格屠刀"

DeepSeek V4-Pro API 永久降至原价 1/4。AI 公司以极低成本即可调用顶级模型 → 自建/租赁算力的紧迫性骤然降低 → 算力租赁估值逻辑重构。市场意识到：下游 AI 公司以极低成本即可调用顶级模型，自建/租赁算力的紧迫性大幅降低。

第二层：结构脆弱性 — 交易过度拥挤

第四层：产业信号 — 大股东高位减持

中微公司、澜起科技等半导体头部公司陆续披露股东减持计划。股价经历迅猛上涨后，产业资本减持直接打击炒作情绪。

第五层：外部环境 — 美联储鹰派 + 全球分化

美国 4 月通胀抬升，美联储释放加息信号，10 年期美债收益率高企压制全球风险资产。但同日德国 DAX +2.01%、韩国综指创新高 → 排除"全球系统性风险"，问题在 A 股内部。
