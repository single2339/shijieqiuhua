问题定义与参考类选择Problem framing and reference classes

把模糊问题压缩成可计算假设、时间范围、成功标准和行动集合，并显式选择参考类。Turns a fuzzy choice into a computable hypothesis, time horizon, success metric, and action set with an explicit reference class.

行动阈值与期望值比较Action thresholds and expected value

用不同先验、证据强度和依赖折扣重跑结果，显式标记结论是否稳健。Re-runs the decision under alternative priors, evidence strength, and dependency discounts to show whether the conclusion is robust.

多轮对话决策循环Multi-turn decision loop

先基于当前信息给弱先验和初步判断，再通过多轮对话追问缺失信息，持续更新先验、后验和决策准备度。Starts with a weak prior and an initial read, then iteratively asks for missing information and updates the prior, posterior, and decision readiness over multiple turns.

过程日志与变化图表Process log and change chart

自动记录每一轮对话里新增了什么信息、如何完成贝叶斯更新、判断为什么改变，并在报告中输出轨迹图和过程表。Records what changed in each round, how the Bayesian update was applied, why the judgment moved, and renders both a trajectory chart and a process table in the report.
