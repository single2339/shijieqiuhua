05
Evidence Model

判断不是裸结论：它由信源、因子和置信度组成

L1–L4 置信度

L1确认≥3 个独立来源 + 强证据 + 高置信因子
L2高可信多源覆盖，包含结构化基本面
L3中可信至少一个来源，关键数据不足
L4推测仅基础输入，不能作为决策依据

Honest Uncertainty

产品把不确定性显性化，而不是强行预测

First-class outcome

信息不足，暂不给方向

当近期状态、历史交锋、阵容或相关媒体证据缺口过大，系统直接输出数据质量原因和复扫建议。

  • structured_stats_unresolved：结构化基本面未解析
  • no_relevant_search_results：搜索结果与比赛不匹配
  • too_early：关键赛前分析尚未发布

08
Engineering Proof

代码已经覆盖关键风险：鉴权、去重、结算、数据不足

01

鉴权不把 token 暴露给前端

`tests/test_auth_security.py` 验证登录返回 HttpOnly cookies，响应体不含 access / refresh token。

02

缓存与并发去重

`warm_cache.py` 使用 provider-aware key、LRU、in-flight Event，避免同场同问重复计算。

03

URL 安全门

`url_safety.py` 限定 http/https、allowlist、DNS 公网 IP，测试拒绝 localhost / metadata IP。

04

信息不足不会伪造成判断

`data_quality.py` 只在 `info_insufficient` 展示缺口原因，正常判断不混入错误诊断。

05

赛后账本有样本门槛

`track_record.py` 低于默认 20 场只展示 settled，避免小样本误导。

06

赔率不进入 OSINT 证据

`tests/test_football_security.py` 与 OSINT 测试确认 Sporttery 仅作结算 fallback，不作为研判证据。
