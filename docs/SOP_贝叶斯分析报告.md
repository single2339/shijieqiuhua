- `Bash` — 运行 Python 脚本

## 标准工作流

### Phase 1：资料收集

1. **主体搜索** — 目标公司/行业的基础信息
2. **行业纵深** — 行业格局、竞争环境、价格等核心变量
3. **机构观点** — 券商研报、评级、目标价
4. **技术面**（仅股票分析）— 股价走势、支撑阻力、资金流向
5. **补充验证** — 针对分析框架中需要确认的关键数据点

### Phase 2：分析框架设计

1. 确定核心问题
2. 设定先验概率 P₀（通常 0.30–0.50）
3. 设计证据维度（通常 5–8 个维度）
4. 计算贝叶斯更新表
5. 应用相关性折扣（通常 0.6–0.85）

### Phase 3：PDF 生成

1. 创建 `generate_{topic}_pdf.py`，WeasyPrint HTML → PDF
2. 排版：正文 Songti SC，标题 Heiti SC，左对齐
3. 运行 `.venv/bin/python generate_{topic}_pdf.py`

### Phase 4：输出规范

文件名格式：`{中文主题}_甲队长.pdf`
