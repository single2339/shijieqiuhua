# 低风险投资之路 — Low-Risk Investing Skill

**Based on**: 《低风险投资之路（第2版）》徐大为、刘颖，2015

## Core Philosophy

低风险 ≠ 低收益，高风险 ≠ 高收益。真正的低风险投资是找到**价格扭曲**（定价错误）的机会，利用安全边际和工具组合，实现可控风险下的超额收益。年化 15% 是合理预期，30%+ 是运气。不要追求一夜暴富。

## Four-Layer Investment Framework

### Layer 1: Toolbox — 了解每个工具的特性

徐大为全书的核心是**工具箱思维**：每个市场阶段都有最合适的工具，低风险投资者的优势在于工具多、切换快。

| 工具 | 年化收益率 | 特点 | 适用场景 |
|------|-----------|------|---------|
| 现金管理 | 2-4% | 零波动 | 任何时候 |
| 债券/债基 | 4-8% | 固定收益，信用风险 | 利率高位、股市高估 |
| 可转债 | 0-30% | 下有保底、上不封顶 | 股市低估、利率高（象限1） |
| 封闭式基金 | 10-20% | 折价+分红 | 折价率足够大时 |
| 分级A | 6-10% | 类固收+看空期权 | 股市下跌期 |
| 打新/套利 | 5-50% | 确定性高、容量有限 | 市场无效期 |

**关键决策规则**（来自第九章的大小类资产轮动）：

- 象限1（股市低估 + 利率高）：以债性为主，可转债提供进攻性
- 象限2（股市低估 + 利率低）：以权益类为主，满仓进攻
- 象限3（股市高估 + 利率低）：保持权益仓位但逐步降低
- 象限4（股市高估 + 利率高）：大幅减持权益，转固收

### Layer 2: Strategy — 三种核心策略

**① 动态再平衡**
- 固定比例（如 50:50）定期强制平衡
- 在震荡市中创造超额收益（书中案例：指数归零，组合赚 26.6%）
- 在单边牛市中会跑输（这是愿意付出的成本）
- **不要择时，用规则代替判断**

**② 轮动策略**
- 基金折价轮动：三等分资金做首尾相接的折价赎回套利
- 分级A轮动：在隐含收益率高的品种之间切换（设置阈值c，超过即换）
- 大小类轮动：权益类与固收类按市场估值切换
- **核心逻辑**：不预测方向，只比较相对价值

**③ 对冲策略**
- 股指期货对冲（期现套利）：买入现货+做空期货，赚取基差
- 折价分级A对冲：利用分级A接近低折时的看空期权特性与指数反向运动
- **对冲的目的是获取固定收益 + 廉价期权，不是零风险**

### Layer 3: Position Management — 仓位管理

**攻守阵型**（足球类比）：

| 角色 | 工具 | 比例 |
|------|------|------|
| 前锋（进攻型） | 封基、股基、分级B、130+可转债 | 视市场调整 |
| 中场（平衡型） | 转股溢价不高的可转债、有保底股票 | 主力仓位 |
| 后卫（防御型） | 现金、短债、债性可转债 | 底部兜底 |

**攻守转换规则**：
- 价格下跌 → 平衡型变防御型 → **减持防御、增持平衡**（增加弹性，为反弹准备）
- 价格上涨 → 平衡型变进攻型 → **减持进攻、增持平衡**（收回弹性，保护利润）

**杠杆纪律**：
- 杠杆率 ≤ 2 倍，极限 ≤ 2.5 倍
- 使用杠杆必须分散持仓（多品种同时黑天鹅的概率极小）
- 保持流动性：至少 30% 仓位可在 1 天内变现
- **杠杆会上瘾，必须用规则约束**

### Layer 4: Risk Control — 风险控制

**① 沙盘演练**（每次投入真金白银之前）：
1. 短期最多能涨多少？（爆发力）
2. 短期最多能跌多少？（最坏情况，即"压力测试"）
3. 如果判断错误，亏损在我承受范围内吗？亏损的时间窗口多久？
4. 如果出现"黑天鹅"，提前想好应对方案

**② 不确定性管理**：
- 一切皆有可能（包括茅台跌50%、转债违约）
- 不确定性不是要回避的，而是要用**概率思维**去定价
- 盈利概率 × 盈利幅度 > 亏损概率 × 亏损幅度 才出手

**③ 认知套利衰减**：
- 任何赚钱模式都会随参与者增加而衰减
- 打新年化从 50% → 10%，期现套利从 30% → 5%
- **当一个策略广为人知时，超额收益就已经没了**
- 持续学习新工具、新市场才是超额收益的来源

## Application Workflow

### 投资规划

```
1. 确定预期收益（15% 够用，30% 是运气）
2. 判断当前市场象限（股市估值 + 利率水平）
3. 选择该象限的主力工具（Layer 1）
4. 设计攻守阵型（Layer 3 前锋/中场/后卫比例）
5. 确定再平衡规则（Layer 2 定期 or 阈值）
6. 设置杠杆上限（Layer 3 ≤ 2x）
7. 对每个新品种做沙盘演练（Layer 4）
8. 持续监控：超额收益是否在衰减？（Layer 4）
```

### 组合诊断

```
- 收益率是否符合预期？→ 如果不是，检查是否跑偏了工具
- 回撤是否超出承受？→ 检查攻守阵型是否错配
- 是否在用自己不理解的工具？→ 退回 Layer 1
- 收益来源是否清晰？→ 需要知道"在赚谁的钱"
- 有没有哪个品种让你睡不着？→ 说明风险暴露过大
```

## Key Quotes from the Book

> 投资如履薄冰，股市绝不是"印钞机"，而不小心就是"绞肉机"。

> 当杠杆比例达到5倍时，资产价格下跌20%就意味着投资者爆仓，资金归零。

> 任何一个赚钱模式，如果高于市场平均回报率，说明市场存在某种无效性。但随着参与者增多，这种无效性会逐渐消失。

> 不想当将军的士兵不是好士兵——在职场上是励志故事，但在股市中，预期年化50%通常不是励志故事，而是悲惨故事。

> 投资不是生活的全部。通过投资实现财务自由，享受生活才是重点。
